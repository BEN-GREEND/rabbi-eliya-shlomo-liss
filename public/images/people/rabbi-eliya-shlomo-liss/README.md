# דיוקן הרב אליהו שלמה ליס

העלה לכאן את התמונה בשם:

    portrait-main.jpg

(מתקבל גם `.png` או `.webp` — יש לעדכן בהתאם את `portrait` ב-`content/site.yml`.)

## המלצות

- רזולוציה: לפחות 1600px בצד הארוך.
- יחס: אנכי, קרוב ל-4:5. הקומפוזיציה בדף הבית בנויה לכך.
- לא לחתוך מראש ולא "לשפר" — סריקה נאמנה עדיפה.
- אם יש גם סריקה ברזולוציה גבוהה, שמור אותה כ-`portrait-main-full.jpg`.

## מה קורה אוטומטית

כל עוד הקובץ אינו קיים, אזור הדיוקן בדף הבית מוצג כלוח ריק ומעוצב
עם התווית "תצוגה ממתינה". ברגע שהקובץ יעלה לנתיב הזה, האזור יתמלא
מעצמו — אין צורך לגעת בקוד.

יש למלא גם `portraitAlt` ו-`portraitCredit` ב-`content/site.yml`.
