# הרב אליהו שלמה ליס — אתר מורשת

מוזיאון דיגיטלי וארכיון חי. עברית, RTL מלא.

## הרצה

```bash
npm install
npm run dev          # http://localhost:3000
```

| פקודה                   | מה היא עושה                                                   |
| ----------------------- | ------------------------------------------------------------- |
| `npm run dev`           | שרת פיתוח                                                     |
| `npm run content:check` | בדיקת שלמות הקשרים בין פריטי התוכן                            |
| `npm run build`         | build לפרודקשן (מריץ `content:check` קודם, ונעצר אם הוא נכשל) |
| `npm run typecheck`     | TypeScript                                                    |
| `npm run lint`          | ESLint                                                        |

## הוספת תוכן

אין צורך לגעת בקוד. כל פריט הוא קובץ בודד תחת `content/`:

```
content/
  timeline/     אירועים בציר הזמן
  torah/        דברי תורה
  gallery/      תמונות
  archive/      מסמכים, מכתבים, תעודות
  testimonies/  עדויות
  activities/   תחומי פעילות
  people/       אישים — מקור האמת היחיד לכל אדם
  _vocab/       תקופות, מקומות וקטגוריות
  site.yml      טקסטים ברמת האתר
```

להוספת תמונה: קובץ חדש ב-`content/gallery/`, והתמונה ל-`public/images/gallery/`.
שם הקובץ הוא ה-slug, והוא חייב להיות זהה לשדה `slug` בתוך הקובץ.

### קשרים בין פריטים

הפניות נעשות תמיד לפי **`id`**, לעולם לא לפי שם או נתיב.
כך שינוי כתיב של שם עברי או שינוי כתובת URL אינו שובר דבר.

```yaml
people: [rabbi-eliya-shlomo-liss] # מזהי אישים
related: [event-placeholder-a] # מזהה של כל פריט באתר
```

הקשר נגזר ואינו נשמר פעמיים: קובץ אישיות **לעולם** אינו מכיל רשימת תמונות.
כותבים `people: [...]` על התמונה, ודף האישיות מוצא אותה לבד.
גם `related` הופך לדו-כיווני אוטומטית — מצהירים פעם אחת, בכיוון אחד.

### בדיקת שלמות

`npm run content:check` מוודא, בין היתר:

- כל `people` / `author` / `recipient` / `narrator` / `mentions` מצביע לאישיות קיימת
- כל `related` מצביע לפריט קיים
- `period`, `places`, `categories` קיימים באוצר המילים
- `id` ייחודי בכל האתר, `slug` ייחודי בתוך ה-collection
- שם הקובץ תואם ל-`slug`
- כל תמונה ומסמך שמוזכרים אכן קיימים תחת `public/`
- לכל תמונה יש `alt`

הבדיקה רצה אוטומטית לפני כל `build`, ולכן reference שבור לא יכול לעלות לאוויר.

## עקרון תוכן

**לא ממציאים כלום.** כל פרט ביוגרפי, תאריך, שם, מקום או ציטוט שלא נמסר

ומוצג עם הקידומת "בערך" — לעולם לא כתאריך ודאי.
